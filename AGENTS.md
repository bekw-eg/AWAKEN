# Работа с репозиторием AWAKEN

- Репозиторий: https://github.com/bekw-eg/AWAKEN.git.
- Пользователь подтвердил рабочую ветку для новых фич: `feature/pose-detection`.
  Сохраняй это имя; не создавай вместо неё ветку `feature` и не меняй основную ветку GitHub.
- Делай коммиты с настроенным Git-автором пользователя: `bekw-eg`.
  Перед коммитом проверяй `git config user.name` и `git config user.email`;
  не заменяй автора на агента и не меняй глобальные Git-настройки.
- В репозитории работают коллабораторы. Перед работой и push выполняй `git fetch origin`
  и проверяй расхождение с `origin/feature/pose-detection`. Сохраняй чужие изменения и историю.
- Отправляй законченные изменения обычным push в `origin/feature/pose-detection`.
  Не используй force push и не переписывай опубликованные коммиты без прямого указания пользователя.
- Добавляй в коммит только относящиеся к задаче файлы. Перед отправкой запускай
  соответствующие изменениям проверки; для кода приложения — `npm test` и `npm run build`.
