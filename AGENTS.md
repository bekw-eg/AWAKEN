# Работа с репозиторием AWAKEN

- Репозиторий: https://github.com/bekw-eg/AWAKEN.git.
- Пользователь подтвердил рабочую и основную ветку: `main`.
  Ветка `feature/pose-detection` сохранена для коллабораторов; не удаляй её без указания пользователя.
- Делай коммиты с настроенным Git-автором : .
  Перед коммитом проверяй `git config user.name` и `git config user.email`;
  не заменяй автора на агента и не меняй глобальные Git-настройки.
- В репозитории работают коллабораторы. Перед работой и push выполняй `git fetch origin`
  и проверяй удалённую историю, включая текущую feature-ветку, если она опубликована.
  Сохраняй чужие изменения и историю. Не используй force push.
- После проверки сделай коммит и обычный `git push -u origin feature/<название-задачи>`.
  На этом задача заканчивается. Не переключайся затем на `main` для merge или push.
- Никогда не мержи изменения в `main` самостоятельно и не выполняй `git push origin main`.
  Пользователь сам создаёт Pull Request и вручную решает, когда мержить его.
- Добавляй в коммит только относящиеся к задаче файлы. Перед отправкой запускай
  соответствующие изменениям проверки; для кода приложения — `npm test` и `npm run build`.
