# Production audit — AWAKEN

Дата: 30 сентября 2026. База: `3d9493e` (`origin/main`), ветка: `feature/production-audit`.

## Исправлено

- **Hands-free recovery:** непустой, но неполный массив landmarks вызывал `TypeError` при сравнении с позой удержания. Обязательные суставы теперь проверяются до обращения к координатам; потеря позы отменяет удержание без расхода заряда.
- **Выбор push-up:** готовая поза одной стороны тела могла привести к чтению отсутствующей точки другой стороны. Сравнение учитывает только доступные достоверные точки; появление новой стороны заново запускает удержание.
- **Повторный урон:** защита хранила только последний ID подхода, поэтому последовательность A → B → A повторно начисляла урон и XP. Теперь сохраняются ID всех разрешённых подходов текущего противника; список очищается между встречами.
- **Повторный старт / смерть:** повторный `start_battle` не сбрасывает активного противника и использованные заряды; удар по уже погибшему игроку игнорируется.
- **Очистка MediaPipe:** исключение из `close()` после сбоя WASM больше не прерывает обработку ошибки и показ Retry. Поток и RAF освобождаются независимо от результата закрытия детектора.
- **Высота арены:** большая сцена босса вытесняла webcam ниже первого экрана. Высота сцены и камеры теперь адаптируется к высоте desktop-окна; HP, видео и управление камерой проверены одновременно в видимой области. Оформление, спрайт и механика анимаций сохранены.
- README сокращён до описания, возможностей, стека, запуска, сборки и краткой механики. Браузерный `scripts/check-motion.mjs` обновлён: старый сценарий ожидал удалённые кнопки ручных атак.

Четыре регрессионных теста воспроизвели ошибки до исправления и проходят после него. Дополнительно проверены повторный старт и удар по погибшему игроку.

## Сохранённые правила и ограничения

- SKIP, согласно текущей реализации и тестам, возвращает в главное меню с сохранённым следующим противником; автоматический переход происходит через пять секунд. Поведение не изменено на переход кнопкой.
- Лечение выполняется жестом: пять секунд удержания, заряд из Training, не более двух применений за встречу и обязательное движение перед повторным удержанием. Отдельной кнопки heal и временного cooldown нет; лечение во время enemy turn недоступно.
- Rage и heavy attack — визуальные состояния; боевой баланс не изменён.
- Навигация хранится в React state, URL-маршрутов нет. Refresh открывает главный экран и восстанавливает проверенный локальный прогресс. Browser Back не является переключателем внутриигровых экранов.
- Для деплоя нужен HTTPS и весь `dist/`, включая модель и WASM. Production API, секретов, локальных файловых путей и запросов к localhost нет; localhost упоминается только в объяснении доступа к камере.
- **Не проверены физические упражнения человека перед реальной камерой, Safari/Firefox и слабые устройства.** Синтетический поток подтверждает запуск движка, но не точность распознавания. Inference остаётся синхронным на основном потоке.
- MediaPipe выводит диагностические предупреждения TensorFlow/OpenGL, включая информационное сообщение CPU delegate через stderr. Они не означают падение приложения; отдельная валидация на целевых браузерах остаётся необходимой.
